# SaffronPass

Luxury interactive animated web invitations and smart multi-event RSVP platform built for Indian weddings and global celebrations.

## Phase 1 & Phase 2 Highlights
- **5 Luxury Themes**: Royal Saffron & Gold, Minimal Ivory, Pastel Udaipur, South Indian Silk & Jasmine, and Dark Sangeet Glam.
- **3 Interactive Openings + Scratch-to-Reveal**: 60fps Wax-Seal Envelope, Royal Palace Doors, Cinematic Scroll Reveal, Falling Particles (Marigold, Rose Petals, Gold Sparkles), and HTML5 Canvas Gold-Foil Scratch-to-Reveal Date card.
- **Tap-to-Start Background Music**: 5 built-in Web Audio API musical loops (Royal Shehnai, Romantic Piano, Sitar Bliss, Celebration Chimes, Acoustic Warmth) plus custom MP3 upload (<3MB) with floating Mute/Play control.
- **Browser-Side WebP Compression & Rich WhatsApp Previews**: Automatic client-side resize (max 1200px) & WebP compression (<300KB) for cover & 4-photo gallery, plus privacy-safe Open Graph metadata & dynamic `/api/og` image generator.
- **5-Tab Host & Co-Host Command Center**: Basics & Design, Sub-Events Schedule, Smart Category Links (with 1-tap Share on WhatsApp), Live RSVPs (Manual phone guest entry, UTF-8 BOM Excel/CSV caterer export with `TOTALS` row, 1-tap guest WhatsApp), and Family Co-Hosts (up to 3 co-hosts via recursion-free `SECURITY DEFINER` RLS).
